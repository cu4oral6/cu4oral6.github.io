      • 光谱变化（ELMM/尺度扰动）的直觉

      0) 先立一个“复现总仓库”（你自己建）

      目的：把环境、数据、命令、输出、表格绘图统一管理，做到别人拿到就能跑。

      你总仓库里至少要有：

      • env/
        • conda_env.yml（或 requirements.txt + pip freeze）
        • hardware.md（GPU/CPU/显存/系统/CUDA）
      • data/（只放下载脚本/软链接，不要把大数据直接提交 git）
        • download.md（每个数据集来源、校验、路径约定）
      • runs/
        • run_all.sh / run_all.ps1（一键复现实验）
        • seeds.txt（比如 0~9）
      • results_raw/（每个方法原始输出：端元、丰度、日志、checkpoint）
      • results_proc/（汇总后的 csv、均值方差、对齐后的端元顺序）
      • figures/（最终论文级图）
      • tables/（最终论文级表：LaTeX/Word 都可）
      • reproduce.md（从零到复现成功的“唯一路径”）

      1) 仓库 A：HySUPP（强烈建议作为你的“统一 benchmark 主框架”）

      HySUPP 的价值：它本来就是为“统一比较 + 可复现”设计的——3 类任务、20 个方法、带数据、带统一入口，非常适合新手打通闭环。仓库结构里就有 config/ data/ src/ utils/ unmixing.py 等。GitHub

      A1. 复现目标（对齐 HySUPP 论文的核心结果）

      • 数据集：3 个合成数据集 DC1/DC2/DC3 + 真实数据 Cuprite。
      • 指标：丰度 SRE、端元 SAD（论文里 Fig.14 用 SRE；Table IV 用 SAD）。
      • 方法集合：HySUPP 一共集成 20 个方法（监督/半监督/无监督），并给出清单。

      ✅ 你要做到的“TGRS级复现”最低标准：
      (1) 把 DC1/DC2/DC3 的 SRE 曲线/柱状图复出来；
      (2) 把 DC1/DC2/DC3 的 SAD 表复出来；
      (3) Cuprite 至少出 1 张端元谱曲线对比 + 1 组丰度图可视化（哪怕只有定性）。

      A2. 入口脚本（HySUPP 的“单一总入口”）

      • unmixing.py（跑实验的统一入口）GitHub
      • HySUPP 用 hydra + MLXP 管理实验；README 里写了“必填参数”：mode/data/model/noise.SNR。GitHub
      • 论文里也给了命令行例子（同一风格）：python unmixing.py mode=semi data=DC1 model=SUnCNN noise.SNR=30。

      A3. 必记参数（写进你的 runs/ 里，保证可复现）

      通用（所有模型都要记）

      • mode: super / semi / blind（监督/半监督/盲）GitHub
      • data: DC1 / DC2 / DC3 / Cuprite（至少这 4 个）
      • model: 方法名（见 HySUPP 清单）
      • noise.SNR: 是否加噪及 SNR 值（对合成数据常用）GitHub
      • seed: 必须固定；HySUPP 支持设置随机种子来保证噪声生成可重复。
      • device/cuda, batch_size, epochs/iters, lr/optimizer（深度方法必填）

      模型级（强制写进 log 的）

      • 每个方法都有 config/model/*.yaml 可以调参；README 甚至演示了改 model.niters、model.noisy_input 的写法。GitHub

      A4. 必出图表/文件（你的“验收单”）

      每次实验（每个 seed）必须落盘：

      • E_hat（估计端元）、A_hat（估计丰度）
      • metrics.json/csv（至少含 SRE、SAD；你建议再加 RMSE/RE 等）
      • command.txt（完整命令行）
      • config.yaml（hydra 展开后的最终参数）
      • stdout.log（训练日志）

      HySUPP 本身就强调：会保存估计端元/丰度，并可用 MLXP 的查询工具做可视化与对比。

      汇总后（跨 seed）必须生成：

      • tables/Table_SAD_DC1_DC2_DC3.csv（均值±方差）
      • figures/Fig_SRE_DC1_DC2_DC3.png（对齐论文 Fig.14 风格）
      • figures/Cuprite_abundance_maps.png

      A5. 数据格式与“自己加数据”的脚手架

      HySUPP 规定 .mat 的统一键：Y/E/A/H/W/p/L/N；稀疏解混还需要字典 D。GitHub
      它还提供 utils/bundle_data.py 把你自己的数据整理成统一格式。GitHub

      这一步对你后面做农业数据非常关键：你可以先把公共农业 HSI（比如 Salinas/Indian Pines）整理成这个格式，哪怕没有 GT，也能跑“盲/无监督/稀疏”方法做定性对比。

      我按你给出的最低学习要求，给你整理一个**“从 0 → 能复现实验 → 有论文雏形”的分阶段学习清单**，并且只补充“刚好够用”的知识（不走偏、不数学劝退）。

      一句话目标（我们始终对齐这个）

      你最终要能：在 PyTorch + HySUPP 框架下，跑通传统 + AE baseline，做对照实验，产出论文级三件套图表。

      阶段 0（预备，不超过 1 天）——你必须“会但不深究”的背景

      你现在需要补充的最小背景

      不是遥感大全，只是 HU 必需件：

      1. HSI 数据长什么样
        • 数据形状：(H, W, B) 或 (B, N)
        • B = 波段数（通常 100–200）
        • 一个 pixel = 一个 B 维向量
      2. 线性代数最低配
        • 矩阵乘法
        • 非负约束（≥0）
        • 列和为 1（softmax / normalization）
      3. PyTorch 必备
        • nn.Linear
        • ReLU / Softmax
        • optimizer.step()
        • 改 lr / epoch / init

      👉 不需要：泛函分析、辐射传输方程、复杂优化推导

      阶段 1 —— 你给出的第 1 条要求（核心概念）

      ✅ LMM：你要能“用人话讲”

      一个像素 = 几种材料光谱的加权平均

      数学上：

      • 端元（Endmember）：
        👉 “纯材料的光谱指纹”
      • 丰度（Abundance）：
        👉 “这个像素里每种材料占多少比例”

      ANC / ASC（一定要能脱口而出）

      • ANC：丰度不能是负的（比例不能 < 0）
      • ASC：比例加起来必须是 1

      💡 AE 中怎么实现？

      • ReLU → ANC
      • Softmax → 同时满足 ANC + ASC

      阶段 2 —— 评价指标（你说的第 2 条）

      你只需要记住**“变好代表什么”**，不背公式

      端元指标

      • SAD ↓（越小越好）
        • 光谱角度
        • 👉 形状越像越好（不看幅值）

      丰度指标

      • RMSE ↓
        • 像素级误差
      • SRE ↑
        • 信噪比意义上的整体质量

      📌 论文写法固定模板

      “Lower SAD indicates more accurate endmember estimation, while higher SRE reflects improved abundance reconstruction quality.”

      阶段 3 —— 传统 baseline（你第 3 条）

      必做组合（选一个就够）

      VCA + FCLS（最推荐）

      你要做到的不是“理解证明”，而是：

      1. 用 HySUPP 或 pysptools
      2. 跑通
      3. 存结果

      📌 你此阶段的判断标准

      • 能画出端元曲线
      • 丰度图看起来“像地物分布”

      阶段 4 —— AE baseline（你第 4 条）

      推荐顺序（难度递增）

      1. uDAS
      2. DAEN

      你要掌握的是：

      项目 你必须会
      学习率 改了会影响结果
      epoch 过拟合 vs 欠拟合
      初始化 随机 / VCA 初始化
      loss MSE / SAD

      📌 关键理解（非常重要）

      AE 不是“深度魔法”，而是
      “用网络学一个满足 LMM 约束的矩阵分解”

      阶段 5 —— 对照实验（你第 5 条，论文关键）

      最小可接受对照实验（只改 1 个因素）

      例如：

      • 同一数据
      • 同一指标
      • 同一初始化
      • 只改：
        • 是否加 SAD loss
          或
        • 是否用 VCA 初始化

      📌 你要写得出来一句话

      “Compared with random initialization, VCA initialization leads to faster convergence and lower SAD.”

      阶段 6 —— 论文核心三件套（你第 6 条）

      你最终必须能自动生成：

      1. 表格
        • SAD / RMSE / SRE
      2. 丰度图

      HySUPP 在你学习路径中的角色（非常关键）

      • ✅ 合成数据（有 GT）
      • ✅ 跑传统 baseline
      • ✅ 统一评价指标
