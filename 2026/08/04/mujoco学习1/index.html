理解 MuJoCo 的运行逻辑

学习目标

弄清楚 MuJoCo 中从模型定义到状态更新的完整流程：

必学概念

概念 作用
MjModel 保存模型结构和参数
MjData 保存当前仿真状态
qpos 广义位置
qvel 广义速度
ctrl 执行器输入
mj_step() 推进一个仿真时间步
mj_forward() 根据当前状态重新计算，但不推进时间
mj_resetData() 重置仿真状态

官方 Python 绑定直接暴露 MjModel、MjData、函数、枚举和常量。其中，数据字段直接对应底层内存，因此保存历史状态时需要使用 .copy()。

1. XML 的整体结构

一个比较完整的 MJCF 文件通常是这样：

1.1 主要标签

标签 作用
<mujoco> 整个模型的根节点
<compiler> XML 编译规则
<option> 重力、时间步长等全局参数
<default> 设置默认属性，减少重复代码
<asset> 加载 mesh、纹理、材质等资源
<worldbody> 世界和机器人运动学树
<body> 刚体以及局部坐标系
<joint> 定义 body 相对父 body 的运动方式
<geom> 定义形状、碰撞和外观
<actuator> 定义控制输入如何产生力或力矩
<sensor> 定义传感器输出

MJCF 的主体是一棵由嵌套 <body> 构成的运动学树；不属于单个 body 的执行器、传感器、约束等，通常放在运动学树之外。

1.2 STL 文件

robot.stl 是机器人或机器人零件的三维网格外形文件，但它本身不是完整的可运动机器人模型。

2. MjModel

此时，model 保存的是编译后的模型，例如：

  • body 的数量
  • joint 的数量
  • actuator 的数量
  • 质量和惯性
  • 关节范围
  • 时间步长
  • 父子关系

3. MjData

data 保存当前状态，例如：

  • data.qpos
  • data.qvel
  • data.ctrl
  • data.time
  • body 当前的世界坐标
  • 传感器输出
  • 接触信息

官方 Python API 使用 MjModel.from_xml_path() 加载并编译 XML，再使用 MjData(model) 创建对应的状态数据。

4.6 ctrlrange 和 forcerange 的区别

区别如下：

属性 作用
ctrlrange 限制输入的控制命令
forcerange 限制 actuator 最终产生的输出力

虽然输入只有 2，但是经过增益和传动后，输出可能很大。此时可以使用 forcerange 限制执行器输出。MuJoCo 分别保存和限制控制输入、激活状态以及执行器力，它们不是同一个量。

什么是“广义位置”？

广义位置就是：

用最少的一组数字，描述整个系统当前的构型。

不同关节，需要的数字不同。

joint 类型 qpos 表示什么 qvel 表示什么
hinge 转动角度，单位 rad 角速度，单位 rad/s
slide 平移距离，单位 m 线速度，单位 m/s
ball 姿态四元数，4 个数 三轴角速度，3 个数
free 位置3个 + 四元数4个 线速度3个 + 角速度3个

所以 qpos 不能一概理解成普通空间位置。
